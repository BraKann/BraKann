### Classification de recettes — NLP `Python`

Projet de TALN basé sur la compétition DEFT2013, classifiant des recettes (plat/entrée/dessert) à partir du titre et des instructions.
Comparaison de plusieurs approches ; le meilleur modèle (TF-IDF + SVM linéaire, bigrammes) atteint un F1-macro de 0.862.
